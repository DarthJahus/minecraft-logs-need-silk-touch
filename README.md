# Logs need Silk Touch

Logs, stripped logs, and wood blocks drop 4 planks instead of the block itself. Silk Touch will get you the original block.

## Blocks covered
All vanilla logs and woods, stripped or not, Overworld and Nether (Crimson and Warped stems/hyphae included).

## Compatibility

### FallingTree
Compatible. With the "Fall items" mode, FallingTree can make some logs drop as items instead of blocks when a tree is felled. In that case, its own drop rules apply instead of this datapack's. This behaviour is configurable in FallingTree's config file.
